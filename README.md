# 📝 Markdown Notes

یه اپ یادداشت‌برداری با Markdown، کاملاً سمت کلاینت — بدون هیچ کتابخانه‌ی بیرونی.

## ✨ ویژگی‌ها

### 📝 Parser Markdown (از صفر)
- Headings (`# H1` تا `###### H6`)
- Bold (`**text**`) و Italic (`*text*`)
- Links (`[text](url)`)
- Code Inline (`` `code` ``) و Code Block (```` ``` ````)
- Lists (مرتب و نامرتب)
- Blockquote (`> text`)

### 🎨 رابط کاربری
- چیدمان سه‌ستونه: Sidebar + Editor + Preview
- Live Preview زنده
- حالت روشن/تاریک
- فونت Vazirmatn برای فارسی

### ⚡ قابلیت‌های پیشرفته
- **Command Palette** با `Ctrl + K`
- **Fuzzy Search** برای یادداشت‌ها
- **سیستم تگ** خودکار
- **Auto-save** با Debounce
- **تاریخچه‌ی نسخه‌ها** (۵ نسخه‌ی آخر)
- **Import/Export** برای MD و HTML
- **TOC** خودکار از Headingها
- **Word Count** و **Reading Time**

### ♿ دسترس‌پذیری (A11y)
- پشتیبانی کامل از کیبورد
- ARIA Labels
- Reduced Motion
- Contrast مناسب

### 🚫 بدون وابستگی
هیچ کتابخانه‌ای استفاده نشده — فقط Vanilla JS.
