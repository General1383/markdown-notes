# 📝 Markdown Notes

یه اپ یادداشت‌برداری با Markdown، کاملاً سمت کلاینت.

## ✨ ویژگی‌ها

- Parser Markdown از صفر (بدون کتابخانه)
- Live Preview با Debounce
- Command Palette با Ctrl+K
- Fuzzy Search
- تگ‌های چندگانه و فیلتر
- تاریخچه‌ی نسخه‌ها
- Import/Export
- Theme روشن/تاریک
- A11y کامل
